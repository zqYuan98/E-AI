# 频道（modules/channels）

按读者关心的维度给“全部动态”分了三个入口，放在侧栏“频道”一节，手机底栏有“商机”“热点”两个标签：

| 频道 | 地址 | 收哪些 | 筛选 |
|---|---|---|---|
| 招标商机 | `/tenders` | 分类 `procurement`（招采、前期与申报） | 阶段：招标/中标、项目前期、申报通知、试点示范；业务线：视频监控、近电预警、边缘计算、智慧工地、质量管控、安全生产 |
| 政策动态 | `/policy-news` | 分类 `policy`（政策标准） | 类型：政策/规划、标准规范；标题旁链到政策文件库 `/policy` |
| 行业热点 | `/trends` | 场景落地、大模型、算电协同、产业动态、研究进展、观点解读 | 按分类切换；标题旁链到热点榜 `/hot` |

频道收的是“全部动态”里的条目，不只精选：招标信息有用与否看是否相关，不看是不是大新闻，所以不卡精选门槛。

## 怎么实现

- 只有网页部分，没有后端：三页都读引擎的 `/api/site/pool`（`category`、`tag`、`q`、`page`），和“全部动态”同一个公开读取层。
- 每个频道收哪几类、给哪些标签筛选，写在 `channels.ts`；分类和标签都是 `industry/taxonomy.ts` 里的词，改词表时一起改（类型检查会报出不在词表里的词）。
- 一次只按一个标签筛选（接口只支持一个 `tag`）；地区、单位这类没有标签的，用搜索。
- 三个路由文件（`web/tenders.tsx` 等）只声明它在手机底栏的位置，页面在 `web/channel.tsx`。
