# 研报库（modules/research）

研究机构的研报，一篇一行：标题、机构、发布日期、摘要、带原话的要点、主题、原文链接。同事在站内 `/research` 浏览和搜索，
完整报告点链接到研报网站（洞见等）上看。

- **不存 PDF 和全文**：要点的原话是研报里的一句摘录，最长 200 字；摘要最长 800 字。
- **不对外**：只有站内页面和 `/api/site/research`（要登录），不进 `/api/v1`、MCP 和 RSS。
- **录入**：后台“资料 → 研报库管理”，单篇填写或粘贴 JSON 批量导入；同一个链接（或 `djId`）再导入就是更新。

## 导入格式

```json
[
  {
    "title": "研报标题",
    "institution": "发布机构",
    "date": "2026-10-15",
    "url": "https://www.djyanbao.com/…",
    "summary": "摘要（800 字以内）",
    "points": [{ "text": "要点概括（120 字以内）", "quote": "研报里的一句原话（200 字以内，逐字照抄）" }],
    "topics": ["电力大模型", "虚拟电厂"],
    "djId": "研报网站上的报告编号（可选，用来认出同一篇）"
  }
]
```

每篇最多 12 条要点、6 个主题；不合格的会逐条报原因，其余照常保存。

## 半自动收录（洞见个人版 MCP）

洞见的凭据只在管理员本人电脑上的 AI 客户端里（个人版 MCP，本人浏览器授权），不放到服务器。每周在 Claude Code 里用
`collect-research` 技能（`.claude/skills/collect-research/`）检索、读摘要、整理成上面的 JSON，管理员过目后在后台批量导入。
服务器定时自动同步要等洞见书面确认个人授权可以用在公司服务器、供多人使用之后再做。
