# 访问统计（usage）

成员每打开一个页面，浏览器报一次到，后台“访问控制 → 访问统计”按天、按成员、按页面看，也可以导出明细。

- **只统计成员。** 管理员自己的访问不计入（浏览器不报，服务端也不记）；需要站点有成员登录（`access` 模块），没有时什么也不记。
- **记什么：** 成员、页面路径（不带查询参数）、页面标题、打开时间、设备（手机或电脑）。不记 IP、搜索词和页面内容。
- **报到：** `web.tsx` 把 `web/beacon.tsx` 放在每个页面底部；页面停留超过半秒才报，`POST /api/site/visit`（`access` 的守卫放行成员的这个写入）。身份由 `server.ts` 向 `access` 的会话接口问，不引用它的代码和表。每个成员每分钟最多记 60 次。
- **保留：** 个人明细在 `usage_visits` 保留 180 天（`types.ts` 的 `RAW_DAYS`）；每天的清理（`retention`）先把过期的日子汇总进 `usage_daily`（只有访问次数和人数，永久保留），再删明细。
- **导出：** 后台导出带姓名的 CSV，每次导出写一条审计（`usage.export`）。
- 上线前把 `site/pages/privacy.md` 新增的“访问记录”一节交给运营方确认，并更新页首的版本和生效日期。
